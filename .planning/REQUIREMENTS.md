# Requirements

## Phase 1: Workspace Shell Pivot

### Experience

- [ ] User opens a workspace-first homepage, not a chat-only bot.
- [ ] User sees sources, ingestion, notes, and chat as separate workspace areas.
- [ ] User understands the empty state without setup docs.

### Ingestion

- [ ] User sees a paste/transcript entry point.
- [ ] User sees target domains: health, self-help, AI.
- [ ] User sees review-before-save as the intended model.

### Sources And Notes

- [ ] User sees a source library surface.
- [ ] User sees a notes/insights surface.

### Chat

- [ ] User sees chat as a grounded workspace tool, not the whole app.
- [ ] First-slice UI does not post to `http://127.0.0.1:8000/chat`.

## Later

- YouTube URL import.
- Transcript cleanup and tagging assistant.
- Source approval workflow.
- Grounded chat with citations.
- Evidence view.
- Search over curated material.
- Saved notes from answers.
- Personal goals/coaching after trust exists.

## Out Of Scope For First Slice

- Auth and multi-user accounts.
- Production RAG.
- Automated transcription.
- Supabase/Postgres/vector migration.
- Open WebUI parity.
- Heavy paid infra.
