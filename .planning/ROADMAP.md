# Roadmap

## Phase 1: Workspace Shell Pivot

Goal: make Better Everyday visibly become a personal source workspace.

Deliver:

- Static homepage shell.
- Sources, ingest, notes, chat areas.
- Domain labels: health, self-help, AI.
- No active first-slice localhost chat call.
- Verification notes.

## Phase 2: Reviewable Source Intake

Goal: add manual paste/transcript source creation.

Deliver later:

- Source draft model.
- Metadata/tags.
- Review before save.
- Local persistence or chosen durable store.

## Phase 3: Grounded Chat

Goal: answer from approved sources with evidence.

Deliver later:

- Safe web/backend boundary.
- Retrieval from approved sources.
- Citation/evidence display.
- Insufficient-evidence behavior.

## Phase 4: Notes And Search

Goal: make source knowledge reusable.

Deliver later:

- Search.
- Saved notes.
- Source browsing.

## Phase 5: Personal Coaching Layer

Goal: coaching only after source trust works.

Deliver later:

- Goals.
- Trusted sources.
- Coaching mode.
